# Today Buddy · 今日芽芽

## 品牌概念

Today 的默认形象是一只圆润、安静、愿意陪你开始今天的小伙伴。以奶白暖象牙为唯一主色，通过浅象牙高光、主体渐变和暖棕阴影制造圆润的 3D 体积；五官只使用同一暖色系的深色值，保持品牌统一。

## 视觉规则

- 身体采用大轮廓和少量细节，缩小到 46px 仍然能识别为 Today 的小伙伴。
- 叶子耳朵和头顶小芽形成独特轮廓，避免普通圆脸卡通形象的同质感。
- 只使用奶白暖象牙一个主色相，其他变化都来自同色系明暗和透明度，避免多色和扁平感。
- 蜜桃橙只用于腮红、领口和闪点，形成清晰的品牌记忆点。
- 头像、App 图标和启动页使用同一只小伙伴，Logo 具备亲和力但不会变成复杂插画。

## 动态行为

- 白色高光带缓慢扫过身体表面，约 6.2 秒一轮。
- 右上角闪点轻微呼吸，约 4.4 秒一轮。
- 动画只作用于光泽与闪点，宠物轮廓和表情保持稳定。

## 使用方式

- `todaylogo.png`：当前确认的奶白色 3D 虚拟宠物主 Logo，保留透明背景和完整上半身。
- today-pet-logo.svg：静态矢量资产，适合网页、启动图、宣传物料和 App 图标。
- today-light-logo.svg、today-orbit-logo.svg：兼容旧引用的同内容文件。
- Avatar：移动端默认头像，使用 React Native 动画实现扫光和闪点呼吸。
- 上传个人头像后，用户头像继续使用真实图片。
